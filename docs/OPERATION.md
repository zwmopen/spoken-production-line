# 完整流程与恢复
素材发现 → 去重 → 真实模板绑定 → 上传 → 服务端计划回读 → 核计划 → 独立原生图 → 下载 → 集中轻验收 → 三版文案 → 正式归档 → usage → 机器人通知GET回读 → 下一套。

正常整套每批最多10张独立原生图片；13页做10+3，已完成5页只补剩余8页。单页用于补页和明确缺陷。禁止总览切图冒充。实际生成数含返修全部记账。
A/B各唯一writer，跨账号并行。提交前持久写意图，提交后存真实消息ID。提交未知先查证，不能盲重发。下载失败只补下载，通知失败只补通知。
控制故障先只读重连最多2次；终态、草稿清楚且独占后原页刷新1次，再失败原实例重开1次。活动生成不打断，状态未知不强杀。
明确限额保存原事件及绝对resetAt，到点核最新状态续任务；没有恢复时间按授权退避。50图/80附件/180分钟是估值，非官方保证。403须区分鉴权、权限与限额。
轻验收看模板整体结构、可读性及关键事实；4格/5格、人物道具和局部比例变化不自动返修。争议页先给用户看实际图。
文案首次要求标题≤20字，小红书1 650–850字、小红书2 700–900字、抖音450–650字且最多5标签、日常分享。轻微长度问题一次本地精简。
按workId关联来源路径、本地模板、在线对话、页资产/哈希、文案、验收、usage、通知回执。模板ID与作品workId不同。
正式套数按唯一workId和实际验收归档时间统计；部分图、暂存、返修和镜像不重复计套。JSON队列与manifest是真源，SQLite和HTML是派生视图。
机器人通知仅tenant_access_token，GET核sender_type=app、msg_type=interactive及完整内容。日报只展示窗口总套数与各线套数，审计详情在本地。
