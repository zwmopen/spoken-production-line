# 扩展能力与 Library 清理路由

## 现有能力复用

- CDP 生产控制：读取同级技能 `chatgpt-cdp-production/SKILL.md` 及实际脚本。复用会话检索、真实母版分支、上传、服务端消息回读、原生图片下载和轨迹导出；是否可用以脚本与现场结果为准，文档列出不等于已实测。当前口述生产线账号独占、生成保护、页级去重及滚动额度规则优先于旧文档5小时、批量确认或加载条隐藏等策略。
- 云端资产治理：读取同级技能 `chatgpt-library-manager/SKILL.md`。复用8799桥接服务和extension/本体，不复制维护第二套扩展或删除器。独立技能负责具体协议，口述中控负责用户指令、账号归属、生产保护及回执。

## 用户指令入口

用户可在当前聊天指定：账号A/B或明确实际账号、文件类型、时间范围、包含/排除条件。例如“预览B账号30天前已本地归档的上传图片，保留模板与在途素材”。范围不清先问缺失条件，独立可执行的生产继续。

1. 核真实登录账号和扩展/Bridge连接；端口不等于身份。离线明确报未接通，不把查询失败当库为空。
2. 先只读索引和筛选，输出精确文件ID、名称、时间、预计空间和排除原因；扩展统计未回传则不猜占用量。
3. 排除母版/模板、当前在途附件、未验收及未落地资源；保护除文件名关键词外还要结合manifest中的模板/源文件ID，不能把关键词当充分保护证据。无法证明安全保留待核。
4. 遵循chatgpt-library-manager的预览确认要求，展示具体候选后取得删除确认，再对冻结候选执行；本次接入不构成删除授权。
5. 删除逐项回读，成功/失败分别记录，刷新库状态。删除Library文件、侧边栏会话软删除、本机缓存清理三者分开，互不代替。
6. 生产中不能为清库导航、刷新、关闭账号唯一生产页面；待当前套闭环空闲后安排。空间已满则留断点、预览可清项；不自行全库删除或顺带清理会话。
