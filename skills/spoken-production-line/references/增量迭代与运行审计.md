# 增量迭代与运行审计

技能入口只做导航，详细规则保留在按流程划分的参考文件、脚本与项目台账中，不以字符上限截断用户已确认要求。新要求先判断是补充、覆盖还是撤销；补充保留已有有效内容，覆盖明确旧新条款及作用范围，历史证据与原图保留。不能因规范写入就标流程验收通过。

每个问题记录触发条件、可见症状、证据、根因、处理步骤、恢复验证、失败替代方案与复查点。规则修复应传递至计划提示、执行前置检查、逐页验收、元数据、派生面板和定时提示中的相关环节，不机械复制全部文档。

低产审计按真实时间线区分：上传、计划、图像提交/终态、下载、验收、文案、归档、通知，以及额度等待、控制故障、人工否决返工、执行空档。分别统计生成候选图、合格页、唯一合格套数；未知耗时不归因。定时任务启用不等于每轮执行成功，核实际动作回执。

最近三小时无合格落地时先查真实在途及可执行事项；长期空档不能用过期限额解释，给出具体恢复动作。用户问进度时报告距最近交付、当前步骤、阻塞、下一动作和证据。单套落地及时通知，日报晚到必须标补发并审计原因。
