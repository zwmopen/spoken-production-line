# 口述生产系统 · 设计方案

## 设计原则

对话就是操作入口。可重复的机械动作固化成脚本；主题、事实核对与创作判断交给AI。持续增量更新本文件，不另建一套相互冲突的流程。不为技能另做可视化面板。通用逻辑通过配置服务不同团队，本机业务路径与账号背景放在共享配置，凭据不写入技能。

## 小流程

| 用户表达 | 输入与执行 | 可交付结果 |
|---|---|---|
| 秋季某地，出生产计划 | 从配置的素材库按季节、地区、流量类型一次选材；选对应模板ID；图片和TXT上传；强化计划提示 | 来源清单、真实会话链接、附件与计划回执 |
| 用这个模板配几套素材 | 本地模板路径/名称解析为稳定ID，从模板注册表读取各账号真实链接 | 每套素材与模板一一对应的计划 |
| 随机模板生产 | 在符合类型且有学习回执的模板中随机选择，记录种子；同账号本批尽量不重复会话 | 可续接任务队列 |
| 全部上传完，集中开始 | 每账号选最多5个就绪计划，累计页数不超过当次预算，逐个发送“1” | 启动回执与通知；3小时后回看 |
| 封面太单调，换这个模板 | 读取指定成品封面，锁定指定模板封面，仅迁移封面 | 新封面文件与版本记录 |
| 多端对齐 | 调用现有多端对齐技能，以本地真源匹配Codex、GPT A/B与云盘 | 路径和真实链接对应表 |
| 整理素材 | 调用素材整理技能，修分类及索引 | 整理回执；不混入当前生产任务 |

## 配置与运行状态

- 本机路径、账号入口、模板注册表、通知入口：共享 `machine-profile.json`。
- 账号状态：运行目录保存 `observedAt`、来源、在线/冷却/上传/生成状态；每次执行读取当前状态。配置里端口存在不代表账号在线。
- 模板身份：稳定ID为主键，名称和路径为展示属性。路径改动时验证新路径并更新配置及引用；禁止猜测缺失地址。
- 状态链：准备 → 附件完整 → 已提交 → 计划就绪 → 启动已提交 → 图片完成 → 下载 → 成品归档。每阶段由对应回执推进。
- 上传统计分别记录图片、TXT、总附件；生成统计分别记录计划页数、已启动页数、实际图片数。
- 用户给出的80附件与50图片/3小时作为预算；真实账号提示优先。不得把预计16套或上传分钟数当作实绩。

## 增量迭代

新经验先判断属于哪一个小流程，更新其输入、动作、回执和恢复方法。生产选材发现分类错误，补整理规则并排除错误素材，继续生产；不扩大为全库整理。机械流程稳定后沉淀脚本，保留可跨AI续接的配置、队列、链接与闭环清单。

## 持续清单与查询

模板数据库沿用项目 `02-模板库/templates-registry.json`；用户阅读和筛选沿用 `_规则与台账/模板多端对照表.csv` 与 `模板对话深度链接清单.md`。多端对齐沿用该目录闭环清单；本次口述生产使用当前任务目录唯一 `闭环清单.md`，不按周新建重复清单。执行前按实际ID、类型、地区、季节筛选，读取对应链接；名称变化时同步展示字段，不改变身份。

每条运行状态需记录对象ID、状态、观测时间、证据与下一步。文档底部追加变更日志：时间、执行者、修改对象、修改内容、依据与未完成项。旧记录保留；旧状态保留观测时间，不能仅凭文档更新时间标成刚验证。清单及时更新便于查询，准确性仍由实物或目标端回读支撑。

## 用户新增设想：实例扩展与切号后续接
新增CDP实例不能只按复制端口认定新账号：需验证登录身份/数据目录/唯一端口/模板映射/账号级预算及单写入者，再注册产线。同账号多个实例仍共享账号预算。用户提出CP切号后约5分钟触发续接与1小时内切3账号不回切首个，当前为设计设想，未授权自动轮换执行，不用切号规避实际限制。未来可记录accountSwitchEvent与recentAccountHistory，确认实际切号成功后恢复真实任务，具体账号可用性仍看工具回执。三小时用于上传滚动账复算；生图按独立实际提示，不以三小时必恢复。到期调度先推进已上传计划生成/归档，再决定是否需要补料，不仅发提醒。

## COCKPIT｜Codex本地账号切换（用户澄清）
名称：COCKPIT。用途：切换Codex本地客户端背后的额度账号，仅Codex产线使用；网页GPT A/B及其他产线暂不使用。状态：候选设想，暂不实施、不自动切号、不安排切号后任务；后续用户要求时再核真实工具与账号接口并运行。此前CP称呼只作为历史口述，实际工具路径与身份接口尚未核实。现有生产继续，不因该设想停工。
