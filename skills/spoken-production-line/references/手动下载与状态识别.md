# 手动下载与状态识别

自动与手动共享同一下载和归档底层能力；额度不足时手动可保存已有内容，不能解除生成额度限制。

- 下载本组图片：只处理当前助手生成图组，同组唯一控件，不给用户附件加下载控件。
- 下载并打包：复用既有本地工作包接口；下载目录和作品库从本机配置读取，不写死机器路径。
- 复制整块三版文案后打包：使用COPY_FORMAT:MULTI与VERSION_START/VERSION_END提取三块实际文案，忽略代码围栏和块外旁白。标记不全不保存。旧无标记内容仅兼容原流程，无法自动保证排除旁白，应改用有标记合同。
- 页面“正在回应”：只表示当前会话当前观察时刻。记录会话URL、最后用户指令、可见停止按钮及时间。不能推断其他会话排队，也不能当成旧任务仍在生成。
- 工作台队列的queued和页面生成状态分别回读；worker.running=false、armed=false时队列记录不是正在执行。
- 模板ID混入其他会话时记录身份冲突，不擅自继续生成。当前生产页有人发送新指令时保留现场，不刷新、切换或覆盖。
