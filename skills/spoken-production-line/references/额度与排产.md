# 额度与排产

> **当前规则（2026-10-16，优先于下方历史记录）：不设每账号每3小时套数硬上限。**只统计实际提交/完成的唯一作品套数，A/B分别记账；每账号内部一次只做一套，整套落地验收后继续下一套。当前运营估值为每账号约50张原生生图/滚动180分钟、约80个上传附件/滚动180分钟（图片、TXT等全部文件都计）；二者是排产估值，不是平台保证，也不是实时剩余额度。按已记录事件逐笔计算，手机或其他设备的用量未知要明示；实际平台限额提示优先，触限即停止对应阶段并留痕。能容纳完整下一套就继续，不能容纳时等到可复查时间后复核，不为撞限或绕限反复试探。
>

上传、原生生图、文本文案分别记账，不共享同一恢复时间。已上传素材可以继续出计划、已生成图片可以继续文案/下载；文本或图片额度受限则按实际提示停止对应阶段。

官方上传说明为最多80文件/3小时，可能高峰降低，失败上传可能计入；每次记录图片、TXT、其他附件、失败尝试及时间。采用滚动窗口，不能声称最后上传后三小时一定全部恢复。为减少调度复杂，可用最后上传时间+3小时+10分钟作为保守首次检查，不代表官方保证。

默认运营估值约80个附件/账号/滚动180分钟（图片+TXT及其他文件全部计数），不额外套用旧75软停止线。整套不可拆；账本显示能容纳完整素材包且平台未提示受限时继续。来源或外部使用不完整时，明确标出未知，平台实际提示优先。

生图约50张/账号/滚动180分钟是当前运营估值，不是官方保证，也不代表实时剩余；历史“每3小时最多5套”及“45张固定软预算”均已被2026-10-16用户最新规则撤销。A/B逐套完整闭环、不设作品套数硬上限；根据本地已知生成量估算能否容纳完整下一套，平台实际提示优先，外部/手机用量未知需明示。

流程：完整上传素材与TXT→收到计划→按已授权计划逐套原生生图→图数/事实/模板验收→三版文案→下载归档/元数据→幂等使用计数。仅有计划不能直接作为已有成图进入归档。三个阶段分别记录成功、失败、限额、最早复查时间。

遇限额停止对应阶段，遵守提示恢复时间；没有明确恢复时间才用本地保守首次检查。检查失败退避，不反复提交；可处理不受影响的下载/归档。不能保证触限造成降智，缺页/错题单独核查任务串线、上下文、原生工具及明确平台提示。

新素材挑选限定同一分组，优先使用次数少且未进入在途任务者；完整作品验收后以workId幂等加1，失败/计划/下载中不加。上传批次不改变原素材使用次数。
