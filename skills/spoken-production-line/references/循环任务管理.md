# 循环任务管理

任务数据独立于技能。生产台账.json为机器记录，CSV/HTML为同源派生视图。不能把CSV历史记录数量当可执行队列。

调度顺序：在途作品安全收尾→用户插队/返工→当前批次→秋季→冬季→春季→夏季→再次扫描秋季新增。插队可指定单个素材、多个素材或主题批次，保存原队列游标，结束后自动回原队列。生成中不抢占。

每个候选绑定源身份、生产年份、唯一workId、优先级、季节、主题、账号、模板、会话、阶段、下一动作及证据；同源在途去重，完成记录不被抹除。无新增不盲目重复，跨年或用户明确复用时建立独立workId并保留历史。

定时任务读取当前配置和最新回执，不复制固定任务页码。检查后必须推进可执行动作；等待有复查时点，卡住有恢复路径。Luna仅作有界只读判断，各账号唯一生产执行者负责实际操作。

核心指标仅为合格本地作品；计划、部分图和用户否决品不计。
